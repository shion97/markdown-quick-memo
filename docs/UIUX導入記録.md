## 維持条件

既存ショートカット、Markdown原文、保存・復元、Undo・Redo、ホットキーを維持する。依存追加は行わない。利用者が作成した未コミットの改善計画は、この記録と分けて保持する。

## Phase 0：現行と画面案

現行画面は上部ツールバー、左の文書タブ、本文、右の目次で構成される。保存の未完了は文書名の丸印のみ。文字数とカーソル位置は上部に置かれ、メニューでは実行項目とショートカットの説明行が混在する。狭幅のタブと目次にはホバー／キー操作で表示する仕組みがある。

比較案は「青い索引」「静かな校正紙」「グラファイト」。通常の文書アプリの操作配置を共通とし、書体・配色・密度を比較する。本文は日本語のシステム書体、コード・数式は既存の原文と装飾の対応を保つ。ライト／ダーク、通常幅／狭幅、長いファイル名、表・コード・数式を含む文書で比較する。画面案は `.impeccable/mocks/decision/` に置く。

UI UX Pro Max の `keyboard focus panel` 検索を使用。フォーカスを見える状態に保つこと、補助パネルが操作対象を覆わないことを採用する。初回の全体検索は紹介ページ向けの結果だったため、画面設計には採用しない。

ImpeccableのOperate方針を適用する。作業画面として既知の操作部品を使用し、配色や余白で役割を明確にする。画面案は画像生成ではなくHTMLで比較する。

状態: 2026-10-28に「静かな校正紙」（paper、code）を利用者が選択した。利用者は全フェーズの導入と維持条件を確認済み。

## 採用仕様

- 上部48pxにタブ開閉、文書名、保存状態、編集／閲覧モード、目次開閉、実行メニュー、ウィンドウ操作を配置する。下部にカーソル位置・文字数を表示する。
- 明るい室内でも夜間でも読み書きできるよう、白／淡いグレーと、青みを含むグレーのダークテーマを対で定義する。日本語本文は既存の16px・行間1.75を基準に保ち、見出しに明朝体を用いる。長文の本文幅は最大800px。表・数式の原文・編集処理は変更しない。
- 保存状態は文書ごとに保持する。無題は「未保存・初回保存が必要」、変更は「未保存」、保存要求中は「保存中」、最新リビジョンが保存された場合だけ「保存済み」。失敗は原因と再試行ボタンを常設し、文字数更新・タブ切替・追加入力で消さない。次の保存成功で解除する。
  同一文書の同じ失敗文言はDOMへ再設定せず、入力のたびに同じ警告を読み上げないようにする。
- 左右パネルは既存幅調整とキー操作を維持する。明示的に閉じたパネルはホバーで開かない。狭幅ではオーバーレイで開き、本文を横へ押さない。閉じる際は本文へフォーカスを戻す。幅変更・見出し更新後も開閉ボタンの状態を更新する。
- 実行メニューはファイル・編集・表示と設定／終了へ整理し、説明専用のショートカット一覧は別表示にする。矢印／Home／Endで実行項目へ移動、Escapeで起点へ戻る。Tabは通常のフォーカス移動を妨げない。
- 空文書の案内はCodeMirrorの外へ置き、入力と同時に隠す。Markdown、Undo、保存・PDFへ混入させない。閲覧モードでも本文の変更を禁止する。

## Direction contract

THESIS: ホットキーから入力を再開するための作業画面。本文の余白を中心に、操作と情報の置き場所を固定する。

OWN-WORLD: 静かな校正紙。白い本文、淡いグレーの補助領域、青みの墨色。選択は淡い青灰色、失敗は文言と赤、フォーカスは輪郭で示す。

STORY: 文書を選び、書き、保存状態を確認して元の作業へ戻る。補助パネルは必要なときだけ開く。

FIRST VIEWPORT: 48pxのツールバー、左240pxのタブ、最大800pxの本文、右240pxの目次、下部の文書情報。狭幅は本文を広く保ち、タブと目次を重ねて開く。特徴的な操作は、本文を押さずに開閉できる補助パネル。

FORM: 利用者が選択したpaperのHTMLスケッチを基準とする。seed:ca6bd29329ee6e7e。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
