# Markdown Quick Memo 企画書

## 目的

短いMarkdownメモを残すたびに高機能なエディタを起動する手間を減らし、Windowsショートカットから即座に入力を開始できる環境を提供する。

## 対象ユーザーと利用場面

対象は開発者本人とする。思いつき、後で確認する事項、作業中の一時メモを素早く記録する場面で使用する。

## 提供価値

- 小型画面をショートカットキーから起動できる。
- 入力欄と装飾表示を同一画面にまとめる。
- 一般的な `.md` ファイルとして保存し、他のエディタでも再利用できる。
- 保存したMarkdownを、必要なときだけ同一フォルダへPDFとして書き出せる。
- WebView2のレイアウトとスクロールを利用し、長い文書でも滑らかに操作できる。
- KaTeXにより、独自の画像合成へ依存せず幅広い数式を表示できる。
- 本体を完全終了しても軽量なRustランチャーからホットキーで再起動できる。
- データベースや独自形式に依存しない。

## 対象機能

新規作成、読み込み、上書き保存、名前を付けて保存、任意のPDF書き出し、検索、Undo/Redo、Markdown装飾、記号の省略表示、リンク操作、ローカル画像プレビュー、Windowsショートカット起動を対象とする。

## 設計上の前提

- Markdown原文を唯一の保存データとし、装飾DOMや数式DOMを保存しない。
- 編集中の本文とUndo・RedoはCodeMirrorだけが所有し、Rustへ定期同期しない。
- `Ctrl + Q`は非表示待機、`Alt + F4`は本体の完全終了とする。
- ホットキー監視は本文を持たないRustランチャーが担当し、完全終了後も再起動できる。
- 外部画像URLは取得せず、ローカル画像と外部リンクのOS連携を制限する。
